# HtmlGifted-cyber.github.io

The online resume of Jeremy A. Henry: author, ordained minister, and Linux & network tech.

**Live: https://htmlgifted-cyber.github.io** · Main website: **https://www.jeremyahenry.com**

## Features
- One page, mobile first: sticky header and an accessible slide-out menu on phones (closes with Esc, a tap outside, or picking a section)
- Sections: About, Projects, Skills, Experience timeline, Education, Ministry, Contact
- Project cards show live GitHub stars, language and last update (GitHub API, cached for an hour)
- "Print resume" button prints a clean one-column resume (print stylesheet)
- Highlights the section you're reading, gentle reveal on scroll (off when "reduce motion" is on), back-to-top button
- SEO: meta description, Open Graph, schema.org Person data, sitemap, canonical URL
- No frameworks or build step: plain HTML, CSS and a little JavaScript; warm earth-tone design
